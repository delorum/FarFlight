# Far Flight — техническая демка

Минимальный 2D-симулятор полёта по приборам для Godot 4. Карта 100×100 км генерируется процедурно и намеренно не показывает положение самолёта. Панель содержит скорость, высоту, вертикальную скорость, компас, авиагоризонт, стрелочные и цифровые игровые часы со стартом в 12:00:00, топливо и два радиоприёмника.

## Запуск

Откройте `project.godot` в Godot 4.4+ и запустите сцену (`F6`/`F5`).

## Управление

- `W` / `S` — увеличить / уменьшить газ;
- стрелки — штурвал: вниз/на себя для набора высоты, вверх/от себя для снижения;
- мышь по рычагу газа или штурвалу — прямое управление;
- нажать на приёмник маяка — переключить его частоту;
- колесо над картой — масштаб;
- ЛКМ и перемещение — двигать карту;
- `Shift` + ЛКМ два раза — провести измерительную линию;
- ПКМ около линии — стереть её;
- `R` — создать новый мир;
- `Ctrl+Q` — выйти из игры.

Поднять газ и скорость выше примерно 70 км/ч, затем взять штурвал на себя. Для безопасной посадки нужно коснуться полосы на скорости ниже 100 км/ч, с небольшим вертикальным снижением и курсом вдоль полосы. При нулевом газе после касания самолёт считается автоматически заторможенным.

## Архитектура

- `FlightWorld` отвечает за seed, рельеф, аэродромы, безопасные коридоры захода и радиомаяки;
- `FlightModel` хранит независимое от интерфейса состояние самолёта и упрощённую динамику;
- `main.gd` рисует карту, изолинии, приборную панель и обрабатывает ввод.

Ветер и погоду можно добавлять в `FlightWorld`, а их воздействие — как отдельные векторы и коэффициенты в `FlightModel`, не меняя карту или приборную панель.
